BUNK:R — PREMIUM INTERACTIVE CONCEPT WEBSITE (REVIEW VERSION)
===========================================================

OPEN THE WEBSITE
----------------
Easiest: open BUNKR_Website_Premium_Standalone.html in Chrome, Safari, Firefox or Edge.
The Standalone HTML includes its images, styles and interactions in one file.
No installation, web server, account, payment service or backend is required.

To publish the full folder version, upload the entire contents of
BUNKR_Website_Premium to a static host and leave the assets folder next to
index.html. The hosted folder version can load the Roboto Condensed font from
Google Fonts; a fallback font is provided if offline.

DESIGN IMPROVEMENTS
-------------------
- Enhanced cinematic industrial layout and premium orange/red design details
- Sticky navigation with active-section indicator and reading progress line
- More polished desktop/mobile typography, transitions and hover states
- Subtle hero motion, scroll reveals and continuous brand marquee
- Reduced-motion accessibility support
- New gallery lightbox with previous/next, arrow keys and touch swipes
- All gallery filter buttons announce the filtered image count
- Improved VIP table selector for 1 to 6 people with exact approved EUR prices
- All four menu tabs dynamically change the menu and accompanying photo
- Keyboard navigation for menu tabs
- Event / membership information dialogs with keyboard-accessible controls
- Mobile hamburger navigation that closes on selection, Escape or outside click
- Keyboard focus outlines, image descriptions and responsive screen sizes

TESTED
------
Browser interaction checks passed in Chromium for gallery, filters, lightbox
navigation, VIP prices, four menus, event and membership dialogs, internal
navigation and responsive layout (320px, 390px, 740px, 820px and 1440px).
No runtime JavaScript errors in the browser test, and no horizontal overflow.

PROJECT LIMITS
--------------
BUNK:R is a SCHOOL BUSINESS CONCEPT, not an operating nightclub.
All images are AI visualisations, and event formats are proposals, not bookings.
There is no ticket checkout, reservation processing or email collection.
Every customer-facing price is shown in euros based on previously approved
Polish prices. No business-model, profit or Shark investment section exists
on the website, as requested.

PRESENTATION QR CODE
--------------------
A working QR code can only be added to the final PowerPoint once the website
has been published and has a real public URL. Do not use a local file path.
